Overview

After completing my introductory Python course in first year, I wanted to keep building on what I'd learned. I decided to try a project that would combine Python with something physical — so I built a system that uses a webcam to detect which fingers I'm holding up and turns corresponding LEDs on and off through an Arduino.

The project gave me hands-on experience with OpenCV for video capture, MediaPipe for hand detection, and PyFirmata2 for communicating with Arduino — all things I hadn't worked with before.

How It Works

The webcam captures my hand, and MediaPipe identifies 21 landmark points on it. Python code then checks which fingers are raised by comparing the y-coordinates of fingertips to their knuckles. Those results are sent to an Arduino through PyFirmata2, and the Arduino switches the five LEDs on or off accordingly.

Vision Library

I used OpenCV to capture frames from my laptop's webcam. OpenCV is a computer vision library that helps process images and videos. The captured frames are converted from BGR to RGB because MediaPipe requires RGB input. MediaPipe Hands then processes each frame and detects the hand when it appears in front of the camera. It identifies 21 hand landmarks, including the finger joints and fingertips, as shown in the image below. These landmark positions are already defined by MediaPipe, so we can access their coordinates and use them in our code. By comparing the coordinates of specific landmarks, we can determine which fingers are raised or folded.

Finger Detection Logic

The program builds a list of five binary values in this order:

fingers = [Thumb, Index, Middle, Ring, Pinky]
# 1 = raised,  0 = not raised

For the index, middle, ring, and pinky fingers, the code compares the y-coordinate of the fingertip landmark to the y-coordinate of the PIP joint. Mediapipe considers top left of the webcam feed as the origin (0, 0). Then y-coordinate of TIP is smaller than y-coordinate of PIP. So: 

FINGER    TIP landmark    COMPARISON landmark
Index     8               6 (PIP)
Middle    12              10 (PIP)
Ring      16              14 (PIP)
Pinky     20              18 (PIP)

for i in range(4):
  tip = hand_landmark.landmark[tips[i]] #tips = [8, 12, 16, 20]
  pip = hand_landmark.landmark[pips[i]] #pips = [6, 10, 14, 18]
    if tip.y < pip.y: #PIP y-coordinates is greater than TIP y-coordinate  
      fingers.append(1) # finger raised
    else:
      fingers.append(0) # finger folded

The thumb is handled differently because it moves horizontally rather than vertically. The code compares the x-coordinate of the thumb tip (landmark 4) against the x-coordinate of landmark 3:

THUMB    tip = landmark 4,  comparison = landmark 3

if thumb_tip.x < thumb_pip.x:
    fingers.append(1)   # thumb extended
else:
    fingers.append(0)   # thumb not extended

There are multiple ways to determine whether fingers are pointing up. I used coordinate-based rule to identify whether each finger is pointing up. This coordinate rule works well when the hand is held upright facing the camera, but tilting or rotating the hand can affect the x- and y-coordinate comparisons.

Once all five values are set, the total number of raised fingers is:

total_fingers = sum(fingers)

Software → Hardware

When a hand is detected, the main script calls LEDControl.LED(fingers), passing the five-element list. The LEDControl.py module uses PyFirmata2 to send each value to the corresponding Arduino pin over USB. The five LEDs are mapped to digital pins 2–6: 

led_1 = board.get_pin('d:6:o')  # Thumb
led_2 = board.get_pin('d:5:o')  # Index
led_3 = board.get_pin('d:4:o')  # Middle
led_4 = board.get_pin('d:3:o')  # Ring
led_5 = board.get_pin('d:2:o')  # Pinky

Hardware

The hardware side of the project is simple — the focus was on the software: python & libraries used: Mediapipe and OpenCV. The physical components are:

  • Arduino board — receives pin states from the computer via USB using the Firmata protocol.
  • 5 LEDs — one per finger, wired to digital pins 2–6 with current-limiting resistors.
  • Webcam — provides the real-time video feed that OpenCV reads frame by frame.
  • Computer — runs the Python script and handles all vision processing; the Arduino only receives the final on/off commands.
  • PyFirmata2 — communicates between Python and the Arduino's Firmata firmware over USB serial.

What I Learned

This was my first time combining multiple Python libraries with physical hardware. A few things I took away from it:

  • How to use OpenCV to capture webcam video and draw overlays on the live feed.
  • How MediaPipe represents a hand as 21 numbered landmark coordinates, and how to use those coordinates to determine finger positions.
  • How PyFirmata2 lets Python control Arduino pins over USB without needing to write Arduino C code.
  • Why splitting hardware control into a separate module makes the code easier to read and debug.
  • What it's like to debug a real-time system where a mistake in software immediately shows up as wrong physical behaviour.

Limitations & Next Steps

The current finger detection relies on simple coordinate comparisons, so it works when the fingers are pointing up and facing the camera. Different hand angles, or poor lighting can affect the hand landmark detection. Although MediaPipe can detect multiple hands, the current python code is set to detect one hand at a time.

Possible improvements I'd like to explore in the future:

  • Improve finger detection to work more reliably across different hand orientations and lighting conditions.
  • Expand the system to support independent gesture recognition and control using both hands.
  • Integrate PyAutoGUI to go beyond controlling LEDs and use hand gestures for computer interactions, such as controlling the mouse, clicking, scrolling, and performing keyboard shortcuts.
